1. El modelo

Variables y objetivo

x₁ = m³/mes de molduras  |  x₂ = toneladas/mes de pellets
Maximizar Z = m₁·x₁ + m₂·x₂ (margen neto por unidad)

Restricciones

2x₁ + 1.5x₂ ≤ materia prima
3x₁ + 4x₂ ≤ horas de secadero
x₁ ≤ capacidad línea de molduras
x₂ ≤ capacidad planta de pellets
x₁, x₂ ≥ 0

3. Cómo se resuelve esto en JS Vanilla

El enunciado plantea dos caminos posibles. Esta página en realidad combina los dos, porque se complementan: la Opción B construye la interfaz que captura los datos, y la Opción A resuelve el modelo matemático detrás de escena.

OPCIÓN A

Librería / Solver JS

Se usó javascript-lp-solver, cargada desde CDN, que implementa el método Simplex (con Big-M para restricciones ≤/≥ mixtas). Recibe el modelo como un objeto JSON y devuelve el punto óptimo sin necesidad de programar el algoritmo desde cero.

OPCIÓN B

Interfaz / Widget interactivo

El formulario de arriba usa addEventListener('submit', ...) para capturar los coeficientes que carga el usuario, arma el objeto del modelo y muta el DOM para mostrar el resultado, sin recargar la página.

En resumen: el formulario captura los datos del usuario, arma con ellos un objeto que describe el modelo (objetivo, restricciones y variables) y se lo pasa al solver, que devuelve el punto óptimo para mostrarlo en pantalla.
